# 跨上下文集成

仅在识别到跨限界上下文或外部模型边界时加载。本包不把 RPC、消息队列、Saga、事件溯源或共享数据库当作默认答案。

## 先定义关系

对每个边界记录上游与下游、模型所有者、客户关系、翻译责任、兼容责任与数据权属。外部系统通过 ACL、OHS、发布语言或其他已证实的关系隔离；不得把对方内部模型直接复制为本上下文模型。

## 再定义契约

契约先表达业务意图、稳定标识、输入输出、授权、失败语义、数据权属和版本兼容。跨上下文只交换发布语言、稳定标识或集成事件；具体 API 和消息格式由能力详细设计校正，不能反向决定领域边界，也不要求一个场景只对应一个 API。

## 一致性按实际选择

记录事务边界、强一致不变量与最终一致可见性。只有实际涉及的机制才加载 database、redis 或 mq 规范，并补充幂等键、顺序、重试、死信/回放、补偿、人工处置和可观测证据。没有真实失败模式时，不预设 Saga、Outbox 或 MQ。
