# 长任务导航

维护决策与证据地图，不要为未知区域编造任务清单。

## 操作流程

1. 写明目标、成功指标和范围外边界。
2. 记录已确认决策、证据和负责人。
3. 识别当前前沿，即能够解锁后续工作的下一个事实或决策。
4. 区分 agent 可执行的调查和必须由人工完成的判断。
5. 每完成一个前沿事项就刷新地图，删除沉积信息和已关闭分支。

前沿事项需要人工判断或外部授权时读取 [references/hitl.md](references/hitl.md)。

不得在证据前沿之外规划详细工作。
