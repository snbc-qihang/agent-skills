# 阶段评审门禁

进入阶段评审且存在尚未闭合的可证伪风险假设时读取。

阶段或切片完成后按风险触发子 Agent 自动评审：先枚举固定 diff 的全部适用反例矩阵单元格和尚未闭合的可证伪风险假设。只有同时满足“固定 diff 涉及安全、事务、跨模块生产合同、发布或不可逆动作”和“未闭合假设集合非空”时，才把集合内彼此不重复的假设全部交给独立子 Agent 覆盖；可合并为一个限制证据范围和验收问题的有界任务，但不得只选择其中一个，也不得重复主 Agent 已完成的全量评审。不满足上述联合条件时使用已选 `code-review` 内联收口；平台不支持委派时逐项内联检查并把无法获得决定性证据的单元格标为 `not_evaluated`，不得据此降低标准门禁或原有人工门禁。用户或仓库明确要求多类独立评审时遵守该要求。

技术通过与人工批准分别记录；不得自行降低既有人工门禁。
