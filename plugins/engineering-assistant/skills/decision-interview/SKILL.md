# 决策访谈

独立调查事实，但把产品选择和重大取舍留给用户决定。

## 操作流程

1. 区分未知事实和必须由人工决定的事项。
2. 从可用源码、运行时或项目记录中查明事实。
3. 只询问答案会改变范围、设计、风险或验收的问题。
4. 按依赖关系排列问题；批量收集相互独立的事实输入。
5. 记录每个答案、后果和未解决阻断项。

多个缺失事实彼此独立时读取 [references/batch-facts.md](references/batch-facts.md)。

不得要求用户重新调查仓库事实，也不得暗自替用户选择重大取舍。
