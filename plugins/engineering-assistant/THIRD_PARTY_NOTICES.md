# 第三方许可与来源

本仓库原创代码与文档使用根目录 [MIT 许可证](LICENSE)。第三方组件保留各自许可证和版权，本项目的 MIT 声明不替代它们。

## 原生启动器

`native/launcher/Cargo.lock` 固定 Rust 依赖。当前启动器的正常依赖为 `serde_json 1.0.145`、`serde_core 1.0.229`、`itoa 1.0.18`、`memchr 2.8.3` 和 `ryu 1.0.23`；下方保留对应许可文本。多许可证组件分别选择 MIT 或 BSL-1.0，原始双重许可仍有效。Rust 标准库许可与第三方声明见 [Rust 1.90.0](https://github.com/rust-lang/rust/tree/1.90.0) 的 `LICENSE-MIT`、`LICENSE-APACHE` 和 `COPYRIGHT`。

## 安装时取得的组件

CPython / Python Build Standalone、Python 依赖和官方 Codex 控制工具在安装时按固定来源和摘要分别取得，不以本项目 MIT 许可证重新授权。它们的许可证保留在各自分布包、安装元数据和上游项目中；更新这些组件时应同时核对其许可证。

## Skill 参考来源与外部 Provider

六个外部项目的 revision、许可证、采用方式及落点由 [`catalog/sources/open-source.json`](catalog/sources/open-source.json) 维护。`fuse` 表示融合已登记原则，不表示整体复制上游；不采用的资产不随插件加载。Anthropic 的 source-available 文档资产排除在采用范围之外。UI/UX Pro Max 的 MIT bundle 通过独立 Provider 合同校验；额外分发 bundle 时必须保留其原始许可证与版权声明。
