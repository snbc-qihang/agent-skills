# 领域建模

使用具体业务场景澄清术语和关系。模型应小于实现；历史名称只能作为明确别名保留。

## 操作流程

1. 从用户语言、接口、数据和现有文档中收集术语。
2. 使用有代表性的成功和失败场景检验每个术语。
3. 解决同义词、含义过载、所有权、不变量和生命周期边界。
4. 只更新一次术语表或模型，其他文档通过引用使用它。
5. 只为真实、反直觉且难以逆转的选择创建 ADR。

只有决策确实需要 ADR 时才读取 [references/adr-format.md](references/adr-format.md)。

不得把 ADR 当作会议记录，也不得在领域模型中复制完整设计。
