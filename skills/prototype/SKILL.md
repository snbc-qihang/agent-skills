# 原型验证

明确一个设计问题，并构建能够回答它的最小可观察产物。实现前先把产物标记为可丢弃。

## 操作流程

1. 定义问题、待比较方案和决策信号。
2. 在适用时复用真实应用外壳和项目约定。
3. 保持数据和行为最小化，但让不确定交互真实可操作。
4. 使用浏览器、测试或评审证据观察原型。
5. 记录答案，并明确选择删除或正式吸收。

界面问题读取 [references/ui.md](references/ui.md)；逻辑或状态问题读取 [references/logic.md](references/logic.md)。只加载适用分支。

不得把原型中的临时捷径悄悄作为生产架构交付。
