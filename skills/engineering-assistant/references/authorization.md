## GPT-6 适配变更说明

复用有效动作授权；保留团队身份与阶段审批要求。

# 授权边界

将普通范围内仓库修改视为明确变更请求的一部分。生产动作、发布、推送、提交、外部消息、破坏性历史修改、凭证、安全敏感变更，以及跨仓库、范围外或不可逆操作需要与动作、目标和范围对应的明确授权；当前对话已有且范围、风险未变的授权直接复用，不再要求第二次确认。

记录审批范围、动作、目标、负责人和过期时间。分析审批不等于执行审批。

满足根 skill 的风险与未闭合假设联合条件时，子 Agent 的有界评审属于已授权质量活动，不需要逐阶段人工确认；未满足时内联收口。主 Agent 应先修复可证实的问题并重新验证；不得把普通阶段完成当作人工审批点。只有生产动作、发布、提交或推送、破坏性修改、安全降级、范围外实现、不可逆产品决策，或多个自动评审结论在证据充分后仍冲突时，才建立人工审批项。

将仓库或项目原有的人工阶段门禁替换为自动评审，只能在已有用户授权或仓库策略明确允许时执行；否则只能提出变更建议，不得静默降低既有人工门禁。已经获准采用自动评审的普通阶段继续按上述规则运行，不因采集参考值超限而恢复成人工阻断。
